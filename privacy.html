HeePic 隐私政策

更新及生效日期：2026年11月23日

鹤壁市黑盒智创信息技术有限责任公司（以下简称“我们”）重视你的个人信息和隐私。本政策说明 HeePic（亦称 HeePic 私密相册 / 保险箱）及其 iOS、Android 和其他正式版本在提供本地保险箱、媒体管理、私密浏览、局域网传输、备份、反馈及相关功能时，如何处理信息。

本政策也适用于官网页面（拟部署于 heebox.site/heepic/）及使用 HeePic 名称的国际版本。不同平台、地区、版本或应用分包可能只提供部分功能；文中标明平台的处理仅适用于该平台。我们不会因你阅读本政策而取得所有权限；依法需要同意或单独同意的处理，应在取得相应同意后进行。

核心说明：你的照片、视频、音频、文件、链接、备忘录和联系人等保险箱内容主要保存在设备本地，我们不提供保险箱内容的自动服务器同步。密码访问保护、文件加密与备份加密是不同的保护措施，各平台实现可能不同。应用的网络配置、反馈、广告和诊断仍可能处理必要的网络或设备信息，详见下文。

一、我们处理的信息

1. 你主动保存的本地内容

当你导入或创建照片、视频、音频、其他文件、链接、备忘录、联系人及文件夹时，应用会在设备上保存相应内容、名称、分组、索引和必要的媒体信息。所选内容可能包含个人敏感信息，请仅导入有权处理的资料。

系统选择器通常只授予你选择的文件、照片或位置的访问范围。导出、分享和创建备份均由你发起。普通导出可能是明文；加密备份使用独立口令或以应用内说明为准。你选择的系统文件提供方、云盘或分享目标会按其自身规则处理已导出的内容。

2. 密码、生物识别和安全状态

应用会在本机处理密码验证、失败次数、游客密码、安全选项及所需的密钥材料。生物识别由 iOS 或 Android 系统验证，我们不会获得原始指纹、人脸模板或系统锁屏密码。你主动启用的一键遮罩、翻转锁定、位置锁、常亮模式或其他安全选项，会受设备能力、系统权限和应用版本限制。我们不接收你的应用密码、备份口令或解密密钥，也无法代为找回，请妥善保管。

3. 相册、相机、麦克风、联系人、位置和本地网络权限

只有在你使用对应功能时，应用才会请求相册、相机、麦克风、联系人、位置或本地网络权限。例如：导入媒体、拍摄或录音、读取你选择的联系人、开启位置锁、在同一局域网内进行电脑传输。拒绝某项权限不会影响与该权限无关的功能。你可以在系统设置中随时撤回权限。

相册用于选择、导入或保存照片和视频；相机用于主动拍摄，以及你另行启用的入侵拍照；麦克风用于主动录音；联系人用于导入所选联系人的姓名、电话号码和邮箱。入侵拍照仅在你开启并授予相机权限后，按功能说明对指定的解锁失败事件拍照，照片保存在本机，可在设置查看、删除或关闭，不用于人脸身份识别或上传。

位置锁仅在你主动开启并授权位置权限后，在本机判断当前是否处于你设定的信任位置，用于决定是否允许解锁。位置信息用于该功能，不用于绘制你的行动轨迹或上传到我们的服务器。

电脑传输仅在你主动开启时在局域网提供临时接收或备份下载服务，不经过我们的公网服务器。局域网 HTTP 本身不提供传输加密，请在可信网络中使用，妥善保管链接并及时关闭。

4. 私密浏览器与剪贴板

当你使用应用内私密浏览器时，会按你输入或选择的地址访问目标网站；目标网站会收到正常访问请求，并按其自身政策处理信息。浏览器历史、收藏和相关设置保存在本机，你可在应用内清除。部分版本可能读取剪贴板中的链接，以提供添加或打开建议；该内容在本机处理。

5. 网站配置、反馈和故障诊断

应用可能向 heebox.site 请求与平台、包名、应用版本、构建号和功能开关有关的配置。服务器为完成通信可能接收 IP 地址、请求时间、网络协议日志和请求信息；该请求不包含保险箱内容、应用密码或相册文件。

当你主动提交反馈时，我们会处理你填写的邮箱、反馈内容、分类，以及平台、包名、应用版本、系统版本、设备型号、语言区域等你提交或应用附带的诊断信息，并记录必要的请求日志，用于回复、排查问题和防止滥用。请不要在反馈中提交密码、备份口令或不必要的私人内容。

部分版本可能使用崩溃诊断服务（如腾讯 Bugly，或国际版本的 Firebase Crashlytics / Analytics）进行稳定性排查和使用统计。相关服务可处理崩溃堆栈、诊断日志、设备型号、系统与应用版本、网络信息及应用实例标识。不得在反馈或诊断中主动附上密码、密钥和不必要的私人内容。

6. 广告和第三方服务

国内版本可能接入穿山甲等广告组件；国际版本可能接入 Pangle。广告服务可能处理设备型号、系统和应用版本、网络状态、IP 地址、广告标识符（如 IDFA，需系统允许）、广告展示、点击和交互信息，用于展示广告、频次控制、反作弊及效果衡量。它们不因接入而取得你的保险箱内容或密码。iOS 访问 IDFA 或开展受系统限制的跨应用跟踪须遵循系统授权；可在系统“隐私与安全性—跟踪”中调整。

  • 穿山甲（北京巨量引擎网络技术有限公司）：国内版广告。隐私政策。
  • Pangle（字节跳动海外广告服务）：国际版广告。隐私政策。
  • 腾讯 Bugly：部分版本的崩溃及性能诊断。服务及隐私说明。
  • Google Firebase：部分国际版崩溃诊断和使用统计。隐私说明。

打开链接、系统分享、应用商店和系统文件提供方按其自身政策处理所需信息。官网访问会产生 IP、时间、请求路径等服务器日志。Cookie 或同类技术如有使用，仅用于完成请求和防滥用。本隐私政策页面不加载广告、统计脚本或外部字体。

二、信息的保存、共享和安全

本地内容由你在设备中管理，保留至你删除内容、清除应用数据或卸载应用。我们不提供服务器自动备份；系统备份、设备迁移或你选择的云文件提供方可能按其设置保存应用数据。卸载、清除数据、丢失设备密钥或忘记密码可能导致内容无法恢复；设备更换或删除应用前，请保留并验证有效备份。

反馈、必要的服务器日志、崩溃诊断和广告服务数据，只在实现相应目的、保障安全、处理争议或履行法律义务所需的期限内保存。除你主动选择的第三方服务、获得你另行同意或法律要求外，我们不会出售你的个人信息，也不会向广告商提供保险箱内容。

我们采用与平台相应的沙盒隔离、访问控制、文件或备份加密和系统密钥保护，并对公网自有接口使用 HTTPS。局域网 HTTP 和第三方连接以功能说明为准。任何系统都不能保证绝对安全；请妥善保管设备、应用密码、备份口令及传输链接。发生个人信息安全事件时，我们将依法采取补救措施、履行告知和报告义务。

三、你的选择和权利

  • 你可以选择是否使用私密浏览器、局域网传输、加密备份、反馈、广告个性化和其他可选功能。
  • 你可以在系统设置中撤回本版实际使用的照片、相机、麦克风、联系人、位置、本地网络和跟踪权限。撤回后，依赖该权限的功能可能停止。
  • 你可以在应用内查看、修改、导出或删除本地内容；删除本地数据前请确认已经保存需要的原件或备份。
  • 你可以联系 heebox2025@heebox.site，申请查阅、更正或删除你主动提交的反馈，咨询个人信息处理或撤回可撤回的同意。为保护账户和他人权益，我们可能要求合理的身份核验。

当前版本通常不要求注册在线账号，因此没有在线账号注销流程。对于只保存在你设备上的内容，我们无法远程解密、读取、删除或找回密码。

我们通常在收到并核实请求后十五个工作日内回复；需要延长或依法不能满足请求时，会说明原因。撤回同意不影响撤回前依法进行的处理，也不影响不依赖该同意的功能。

四、未成年人信息

未成年人应在父母或其他监护人指导下使用 HeePic。不满十四周岁的未成年人使用涉及个人信息的功能时，应由监护人阅读并同意本政策，并协助管理系统权限、密码和备份。监护人可通过上述邮箱联系我们。

五、政策更新

当处理目的、信息种类、第三方服务或适用平台发生实质变化时，我们会更新本政策，并在需要时通过应用内提示、官网或其他适当方式通知并重新征求同意。更新后的政策会在本页面公布，并显示新的更新日期。
