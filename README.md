# HeePic Website

HeePic official site, privacy policy and terms of service.

## Public site (GitHub Pages)

After Pages is enabled, the public URLs are:

- https://heebox.github.io/heepic-website/
- https://heebox.github.io/heepic-website/en/
- https://heebox.github.io/heepic-website/privacy.html
- https://heebox.github.io/heepic-website/terms.html
- https://heebox.github.io/heepic-website/privacy-en.html
- https://heebox.github.io/heepic-website/terms-en.html

Source repository is private; the published Pages site is meant to be publicly readable for App Store / Google Play review.

## Local preview

Open `index.html` in a browser. No build step.
